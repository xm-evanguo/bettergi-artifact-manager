# BetterGI 圣遗物整理助手

一个独立的 BetterGI 脚本项目，用于分析圣遗物库存，给出保留、试强化和清理建议。角色权重与参考分数据来自 miao-plugin（MIT）。

当前为本地原型：可以分析库存快照，生成整理报告和强化顺序；游戏内识别扫描尚未在 Windows 实机验收。本项目不会执行分解、强化、解锁或卸下装备。

## 快速体验

开发环境使用 Bun，无需安装依赖：

```sh
bun test
bun run check
bun run demo
```

然后打开 `output/demo/report.html`。示例包含 9 件虚构圣遗物，结果为保留 6 件、优先试强化 1 件、可清理 2 件。示例与你的账号无关，示例角色规则只用于演示，不是当前版本攻略。

## 安装到 BetterGI

```sh
bun run package
```

把生成的 `dist/ArtifactManager` 整个文件夹复制到 Windows 上 BetterGI 的 `User/JsScript/ArtifactManager`，再在脚本任务中添加该项目。不要只复制 `main.js`，也不要粘贴到内置“自动分解”的表达式框中。

首次运行请选择“示例报告”，确认脚本能正常加载。报告保存在脚本目录的 `saved_files/report-时间戳.html`，同时生成同名数据文件。示例模式不读取游戏画面。

目录结构和接口已对照 BetterGI 0.66.3-alpha.1 源码核对，但尚未在 Windows 上实际导入运行。

## 三种运行方式

| 运行方式 | 输入与行为 | 当前限制 |
| --- | --- | --- |
| 示例报告 | 使用内置的虚构库存和规则 | 可在 Bun 中完整验证 |
| 分析快照 | 读取 `saved_files/inventory.json` 和角色配置 | 支持本项目格式及 OCRArtifacts 导出的数组；缺失字段一律进入待复查 |
| 实验扫描 | 手动打开圣遗物背包后，逐件点击并保存识别原文 | 仅支持简体中文、1920×1080 画面；不改变锁定、等级或穿戴；结果始终标为未核对 |

实验扫描默认只读一页。开始前请取消筛选并滚到顶部，再在设置中勾选“已准备”。扫描器不会主动打开背包；页面或分辨率检查不通过时不会点击。

翻页、末页位置、锁定状态和星级识别尚未验收，所以扫描结果不会直接产生“可清理”结论。即使数量一致，也不能证明没有重复或遗漏。

## 配置自己的角色

把 `script/ArtifactManager/data/default-config.json` 复制为脚本目录中的 `saved_files/config.json`。主力角色、备用角色和空位目标可以在 BetterGI 设置中填写，也可以写在配置文件中。字段说明见[数据与规则](docs/DATA.md)。

当前版本需要手动填写玩法规则，但不需要修改脚本代码。不要把示例配置用于真实清理；真实模式会拒绝带有示例标记的配置。

填写角色名只表示该角色在整理范围内，不代表已有核对过的当前版本攻略。上游评分权重只作参考，套装、主词条和玩法规则需要单独核对来源及适用版本。

以下任一情况会关闭全部清理建议：角色缺少规则、角色名单未确认、扫描不完整、任一圣遗物识别不确定。

也可以在命令行中分析：

```sh
bun tools/analyze.js <库存.json> <配置.json> <输出目录>
```

## 报告内容

报告把每件圣遗物分为保留、优先试强化、可清理和待复查四类，并列出原因、适配角色和本次扫描位置。

强化顺序以主力角色优先，每次只建议强化到下一个检查点（+4、+8、+12、+16、+20）。等级变化后请重新扫描；扫描位置会因排序或强化而改变，不能当作固定编号。

报告支持搜索、按类别筛选和按强化顺序排序。所有数据只保存在本地，不上传账号信息。

## 完成范围

已完成：脚本目录与设置、上游评分适配、快照校验、保留与冗余判断、分段强化建议、只读网页和数据报告、实验扫描器。

未完成：攻略自动更新、可靠的全背包识别、全局最优配装、游戏内自动选择分解件或自动强化。

本版本只对有充分替代依据的重复件建议清理，不会为了达到空位目标而放宽标准。
